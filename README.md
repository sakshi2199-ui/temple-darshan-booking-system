# Temple Darshan Booking System

A full-stack MERN application that allows users to book temple darshan slots online.

## Features

- User Registration & Login
- JWT Authentication
- Role Based Access (User / Admin / Organizer)
- Temple Listing
- Darshan Slot Booking
- Booking Management
- Online Donations
- Admin Dashboard

## Tech Stack

Frontend:
- React.js
- Bootstrap
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

Backend

cd backend
npm install
npm run dev

Frontend

cd frontend
npm install
npm start

## API Testing

Use Postman to test APIs.
